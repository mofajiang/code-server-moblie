## 🎯 使用场景示例

### 场景 1: 文件管理

```
1. 左下角点击「文件」打开资源管理器
2. 右上角点击网格图标切换网格视图
3. 长按任意文件打开快捷菜单
4. 选择「新建文件夹」创建目录
5. 左滑旧文件 → 删除不需要的文件
6. 右滑文件 → 重命名为更清晰的名称
```

### 场景 2: 快速写代码

```
1. Ctrl+Shift+P 打开命令面板（或点击浮动按钮）
2. 切换到「代码片段」标签
3. 点击「全部」分类查看可用片段
4. 点击「函数」插入函数模板
5. 编辑光标处自动填充代码模板
6. 再次打开插入「for 循环」片段
7. 继续插入「log」输出调试
```

### 场景 3: 终端操作

```
1. 点击底部「终端」切换到终端视图
2. 点击左下角浮动按钮打开快捷命令栏
3. 点击「ls」快速输入 ls -la
4. 点击「npm」快速输入 npm
5. 输入部分命令后，搜索历史找到之前使用过的命令
6. 长按选中输出文字
7. 点击浮动的复制按钮复制选中内容
```

## 🔧 技术实现亮点

### 1. 网格视图切换

```javascript
// 动态切换 CSS Grid 布局
explorer.classList.toggle('grid-view');
grid-template-columns: repeat(auto-fill, minmax(100px, 1fr));
```

### 2. 滑动手势识别
```javascript
touchstart → 记录起始 X 坐标
touchmove → 计算位移差
touchend → 判断方向（左滑/右滑）
  diff < -100px → 删除
  diff > +100px → 重命名
```

### 3. 代码片段插入
```javascript
// 检测编辑器状态
if (editor.isContentEditable) {
  document.execCommand('insertText', false, snippet);
} else {
  dispatchEvent('vscode-insert-snippet');
}
```

### 4. 终端快捷命令
```javascript
// 注入到终端输入框
terminalInput.value = cmd;
terminalInput.dispatchEvent(new Event('input'));
```
