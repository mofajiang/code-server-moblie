## ✅ P0 核心功能展示

### 1. 底部导航栏

**触发方式**: 自动显示（手机模式）

**功能**:
```
┌─────────────────────────────────┐
│  [文件] [搜索] [Git] [终端] [设置]  │ ← 5 个快捷按钮
│   ↑      ↑      ↑      ↑      ↑   │
│  图标 + 文字，Active 状态指示       │
└─────────────────────────────────┘
```

**特点**:
- ✅ 固定底部，高度 56px
- ✅ 横屏自动隐藏
- ✅ Touch 激活反馈
- ✅ iOS Safe Area 支持

---

### 2. 手势操作

**触发方式**: 触摸屏幕

| 手势 | 功能 |
|------|------|
| 左滑 | 打开侧边栏 |
| 右滑 | 关闭侧边栏 |
| 双指捏合 | 缩放字体 (12-24px) |
| 双指展开 | 放大字体 |
| 长按 | 显示右键菜单 |

**视觉反馈**:
- 滑动时边缘显示渐变指示器
- 触摸按钮时高亮背景

---

### 3. 字体缩放

**触发方式**: 双指捏合/展开

**效果**:
```
初始：14px
捏合 → 12px (最小)
展开 → 24px (最大)
```

**特点**:
- ✅ 实时调整
- ✅ 键盘显示时自动隐藏控件
- ✅ 跨编辑器会话保持

## ✅ P1 重要功能展示

### 4. 深色模式自动切换

**三种触发模式**:

#### 模式 1: 系统跟随
```javascript
自动检测系统设置
iOS: 设置 → 显示与亮度 → 深色/浅色
Android: 设置 → 显示 → 深色主题
```

#### 模式 2: 时间表
```javascript
默认时间：18:00 - 07:00 (夜间模式)
可自定义：
- 开始时间：HH:mm
- 结束时间：HH:mm
```

#### 模式 3: 电量优化
```javascript
电量 ≤ 20% → 自动开启深色模式
（AMOLED 屏幕省电）
```

#### 手动切换
```javascript
点击深色模式按钮 toggle
记住用户偏好
```

## 🎯 使用场景示例

### 场景 1: 早上通勤路上（7:30 AM）

```
1. 手机打开 code-server → 自动浅色模式（时间触发）
2. 双指捏合调整字体到 16px
3. 点击底部「文件」切换到资源管理器
4. 左滑打开侧边栏查看文件结构
5. 长按文件显示上下文菜单
```

### 场景 2: 晚上加班（9:00 PM）

```
1. 自动切换到深色模式（时间触发）
2. 双指展开放大字体到 18px（护眼）
3. Ctrl+Shift+P 打开命令面板
4. 输入「保存」快速保存所有文件
5. 点击底部「设置」调整配置
```

### 场景 3: 电量告急（15%）

```
1. 自动切换到深色模式（省电）
2. 性能模式自动启用（减少动画）
3. 快速完成编辑并保存
```

## 🔧 技术实现亮点

### 1. 性能优化
```javascript
// 低端设备自动降级（≤2GB RAM）
deviceMemory <= 2 → 禁用动画
passive listeners → 流畅滚动
will-change: auto → 减少重绘
```

### 2. 键盘处理
```javascript
// VisualViewport API 检测键盘
keyboard visible → CSS class + custom property
自动滚动输入框到视野
防止遮挡
```

### 3. 手势识别
```javascript
touchstart → 记录起始位置
touchmove → 计算位移
touchend → 判断手势类型
< 300ms + > 100px → Swipe
2 touches → Pinch
> 500ms hold → Long press
```

### 4. 持久化存储
```javascript
localStorage:
- vscode-mobile-theme → 主题偏好
- vscode-mobile-commands → 命令使用统计
```
